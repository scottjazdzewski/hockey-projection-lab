# Hockey Projection Lab

Standalone development site for the hockey prediction project.

This repository is intentionally isolated from Rail & Rye Racing. Do not bind Rail & Rye routes, domains, D1 databases, R2 buckets, secrets, or production assets to this project.

## Cloudflare
Deploy this repository as its own Cloudflare Pages/Workers project. Keep the temporary site on its own `pages.dev` or `workers.dev` address.
